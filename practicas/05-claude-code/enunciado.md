# 05 - Configuración y control de una herramienta dedicada

Leer conceptos/04-claude-code.md. Separar convención compartida, regla por rutas, procedimiento invocable y control ejecutable. Los archivos de ejemplos no están activos en el proyecto.

La [política de solución](solucion.ts) representa una herramienta dedicada de despliegue. Una aprobación válida viene de un registro confiable con releaseId y digest exactos; un argumento approved del modelo no la sustituye. Se asume que todas las llamadas de despliegue de este fixture pasan por esa herramienta. No afirmar que la prueba cubre todas las vías de una infraestructura real.

Proponer casos permitidos, no aprobados, cambios de digest e identidad de herramienta desconocida. Después ejecutar la solución y revisar los [ejemplos](ejemplos/LEEME.md). Para CI, explicar cómo evitar interacción y duplicados de hallazgos con las interfaces de la versión real.

**Tu propia configuración (ejercicio escrito).** Escribe tu versión de la configuración de Abeduls: un CLAUDE.md de proyecto, una regla para `.claude/rules/` con `paths` en el frontmatter y una skill con frontmatter (`context: fork`, `argument-hint` y un límite de herramientas: `allowed-tools` según la guía, `disallowed-tools` en la versión actual; ver la tabla de mecanismos). Guárdalos en `practicas/05-claude-code/alumno/` (crea tú la carpeta al hacer el ejercicio) con el sufijo `.alumno.md`, por ejemplo `CLAUDE.alumno.md`, `regla-tests.alumno.md` y `skill-revision.alumno.md`, para que Claude Code nunca los cargue en este proyecto. Después compáralos con los [ejemplos](ejemplos/LEEME.md) y con la tabla de mecanismos de [conceptos/04-claude-code.md](../../conceptos/04-claude-code.md): ¿cada instrucción está en el mecanismo y el ámbito adecuados?

*Opcional, no necesario para el ejercicio:* copia los tres archivos con sus nombres reales (`CLAUDE.md`, `.claude/rules/tests.md`, `.claude/skills/<nombre>/SKILL.md`) en una carpeta temporal vacía FUERA de este proyecto, abre Claude Code allí y mira con `/context all` qué se carga. Una regla con `paths` solo se carga cuando Claude lee un archivo que coincide, así que hace falta un prompt que lea uno (por ejemplo, crea un `ejemplo.test.ts` en esa carpeta y pídele que lo lea). Esto gasta cuota de la suscripción que ya tienes, no la API. Borra la carpeta temporal al terminar.
