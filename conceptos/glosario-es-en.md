# Glosario español-inglés

| Español | Inglés | Significado práctico |
|---|---|---|
| Flujo predefinido | workflow | El código establece los caminos posibles. |
| Bucle de agente | agentic loop | El modelo decide acciones a partir de resultados de herramientas. |
| Herramienta | tool | Operación invocable con contrato de entradas y salidas. |
| Resultado de herramienta | tool result | Observación devuelta y asociada a una llamada concreta. |
| Motivo de terminación | stop reason | Estado de protocolo; no confundir con texto de despedida. |
| Coordinador | coordinator / orchestrator | Descompone, delega, agrega y detecta lagunas. |
| Subagente | subagent | Especialista con contexto y herramientas acotados. |
| Traspaso | handoff | Entrega estructurada de hechos, intentos y siguiente decisión. |
| Aplicación anfitriona | host | Coordina clientes MCP y el uso del modelo. |
| Recurso | resource | Contenido direccionable expuesto por un servidor MCP. |
| Esquema | schema | Contrato de estructura y tipos; no prueba veracidad. |
| Campo que admite nulo | nullable field | Puede tener null sin inventar un dato desconocido. |
| Campo opcional | optional field | La propiedad puede no estar presente. |
| Ejemplos de demostración | few-shot examples | Casos concretos para enseñar formato y distinciones. |
| Fuente o sustento | grounding | Correspondencia de una afirmación con evidencia disponible. |
| Procedencia | provenance | Origen, ubicación y fecha de la evidencia. |
| Contexto | context | Información disponible en la solicitud actual. |
| Compresión | compaction | Reducir contexto conservando estado y referencias útiles. |
| Punto de control | checkpoint | Estado o decisión que se verifica antes de continuar. |
| Hook previo / posterior | pre-tool / post-tool hook | Intercepta antes del efecto o trata después el resultado. |
| Permiso | authorization | Derecho comprobado a realizar una operación concreta. |
| Error transitorio | transient error | Puede resolverse al repetir bajo límites y condiciones. |
| Reintento acotado | bounded retry | Repetición con límite y causa que pueda resolverse. |
| Resultado parcial | partial result | Parte lograda, diferenciada de las lagunas pendientes. |
| Evaluación | evaluation / eval | Tareas y criterios para medir un comportamiento observable. |
| Falso positivo | false positive | Hallazgo reportado como problema que no lo es. |
| Calibración | calibration | Comparar confianza declarada con precisión observada. |
| Muestra estratificada | stratified sample | Seleccionar casos por segmentos relevantes. |
| Lote | batch | Trabajo asíncrono que tolera una ventana de procesamiento. |
| Conjunto de reserva | held-out set | Casos separados de los usados para ajustar el sistema. |
| Contrapartida | trade-off | Mejora con coste o limitación que debe justificarse. |
