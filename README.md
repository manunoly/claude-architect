## Verificación local

Con una versión de Node.js que soporte `--experimental-strip-types` (verificado con Node 24.22.1):

```sh
node scripts/ejecutar-practicas.mjs
node scripts/verificar-biblioteca.mjs
```

Las prácticas no requieren claves, instalación de paquetes ni llamadas a la API. Este es un proyecto de estudio independiente; sus preguntas y criterios internos no constituyen una evaluación oficial ni garantizan aprobar una certificación. La biblioteca conserva fuentes de terceros con su procedencia.
